# DreamVPN

VPN-клиент для Windows с интерфейсом-глобусом. Своих серверов не даёт: работает с твоими подписками и ключами
(`vless://`, `trojan://`, `hysteria2://`, `ss://`, `vmess://` и ссылки-подписки).

- Весь трафик идёт через TUN-адаптер, без локальных открытых прокси-портов.
- VLESS/Trojan/VMess работают на **Xray-core**, Hysteria2 и Shadowsocks на **sing-box**; TUN, маршруты и DNS ведёт sing-box.
- Подписки хранятся в виде сворачиваемых папок; на глобусе серверы показаны по странам.
- Требует прав администратора (запрашивает UAC сам).

## Приватность
Подписки и ключи сохраняются только на твоём компьютере (`%APPDATA%\dreamvpn\`), в сборку и репозиторий не попадают.
Не коммить папку `run\` (в ней конфиги с ключами), логи ядра и скриншоты, где видны ссылки подписок.
Приложение обращается в сеть только к твоей подписке, к серверам из неё и (если настроено) к адресу обновлений.

## Ответственность
Это только клиент. Используй его с серверами, к которым у тебя есть законный доступ, и соблюдай законы своей страны.
Ядра в `bin/` распространяются под собственными лицензиями.
