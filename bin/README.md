# bin/

Сюда кладутся ядра (в репозиторий они не входят, скачай с официальных страниц):

| Файл | Откуда |
|---|---|
| `xray.exe` | https://github.com/XTLS/Xray-core/releases (`Xray-windows-64.zip`, берись за самую свежую версию) |
| `sing-box.exe` | https://github.com/SagerNet/sing-box/releases (`sing-box-<версия>-windows-amd64.zip`, версия 1.12 или новее) |
| `wintun.dll` | https://www.wintun.net/ (`wintun/bin/amd64/wintun.dll`) |

Скачивай только с этих страниц: программы работают с правами администратора и видят весь трафик.
